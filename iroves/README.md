# Iro — Platinum Noir

A cinematic full-colour portrait, charcoal name, bold angular gold pattern with moving highlights behind the body, and large contact text. No pause button. The page adapts to the available phone viewport; reduced-motion preferences are respected.

Mobile: 0421 701 204. Instagram: @IroBarcellos. Both are clickable. Save contact downloads a vCard.

## Upload to GitHub Pages

Extract the ZIP, then upload its contents into the repository's main directory: index.html, style.css, app.js, contact.js, and assets. Do not upload the ZIP or an enclosing folder.

In GitHub Settings → Pages, select Deploy from a branch, main, / (root), and Save. Open the resulting Pages address on your iPhone, then write that address to your NFC sticker as a URL.

To change details, edit contact.js. No paid card platform, external fonts, tracking, or build step is required. The original portrait remains unchanged; its light effects are rendered in the page.
