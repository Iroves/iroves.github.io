UPLOAD TO GITHUB
1. Open your GitHub repository and folder Bruno-Giuffre-NFC-Card.
2. Replace index.html and add/replace style.css and app.js from this archive.
3. Keep the existing profile.jpg, university-sydney.png and royal-north-shore.png files in your repository.
4. Wait for GitHub Pages to publish; hard-refresh the webpage (Ctrl + F5).

The photo and institution logos load from the existing publicly hosted GitHub Pages assets:
  https://iroves.github.io/Bruno-Giuffre-NFC-Card/
Consequently the ZIP is a complete CODE update but is not an offline image archive.

All of Bruno's displayed factual details were copied from the live site.
The original institution logo artwork is retained, rather than inventing new or altered coats of arms.
These are raster images. A genuine sharp, transparent vector conversion would require
verified official SVG/EPS originals (or larger original artwork) to avoid distorting their heraldry.
The new design shows the logos on clean white panels at restrained display sizes for clarity.

The vCard button downloads Bruno's contact details.
No additional professional claims or credentials were added.
