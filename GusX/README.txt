INNER GUS — NFC DIGITAL BUSINESS CARD
====================================

READY FOR GITHUB PAGES — NO PAID HOSTING OR DOMAIN NEEDED

1. Open index.html to preview the mobile-friendly digital card.
2. On GitHub, open the repository that powers your NFC URL.
3. Upload index.html, styles.css, main.js and the complete assets/ folder
   to the TOP LEVEL of the repository. Keep all file names unchanged.
4. Make sure GitHub Pages is enabled at Settings > Pages > Deploy from a
   branch > main > /(root). Give GitHub a minute to publish the website.
5. Open your existing GitHub Pages address on your phone. Your NFC sticker
   can continue pointing to the SAME address as before.

TO ADD THE ART WEBSITE LATER:
Open index.html in a text editor. Look for the ART SHOP button, currently
starting with:
  <button class="action action--art action--soon" ... disabled ...>
Replace that element with an <a> element with href="YOUR-URL" and remove
"disabled" plus the "action--soon" class. Keep the same inner artwork/icons.
Or ask ChatGPT to update the website and generate a fresh ZIP for you.
