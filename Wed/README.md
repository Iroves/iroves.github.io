# Collective Wedding Styling – luxury NFC landing page / concept

## Contents
- `index.html` – mobile-first landing page
- `styles.css` – warm wedding-luxury design, subtle animated gold trails
- `script.js` – share button and downloadable vCard

## How to use
Open `index.html` in any modern browser. For a public NFC link, upload the three files into a GitHub Pages repository or your chosen static web host.
