# Glen Coxon — Midnight Blue NFC Digital Card

A redesigned version to replace the existing `iroves/Glenc` GitHub Pages profile. No About box.

## Design

- Rich midnight navy and brushed-silver colours, inspired by Glen's original printed business card.
- Portrait blends into the animated page instead of sitting in a separate photo box.
- Includes a lightweight 6-second MP4 video background, with a still-image fallback and a Pause motion button.
- Three service features: Restoration, Interiors, Exteriors.
- Call link, Save Contact (.vcf), and Share Card buttons.
- Works on GitHub Pages with no paid services, database, or external libraries.

## Installation / update

1. Extract the ZIP.
2. Open your GitHub repository `iroves/Glenc`.
3. Replace **index.html**, **style.css**, **config.js**, **app.js**, and the entire **assets/** folder with the new versions. Do not upload the ZIP itself.
4. Keep `index.html` at the root of the repository.
5. Commit your changes, wait for GitHub Pages to publish, and open:
   https://iroves.github.io/Glenc/index.html
6. If you see the previous design, refresh or open the page in a private browser tab.

The website URL and NFC tag can remain unchanged.

## Details / changes

Change the name, telephone number, trade, and photo in `config.js`.
No email, social profile, portfolio photos, or contact data were invented.

The portrait is a previously-created stylised representation using Glen's supplied reference photograph, not an unedited photographic image. Confirm approval before publishing it on his behalf.
