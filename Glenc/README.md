# Glen Coxon — Improved NFC Card

This version improves the painter layout by aligning it more closely with the original business card style:

- cream and blue colour direction
- sweeping blue curved accents inspired by the card artwork
- cleaner typography and spacing
- portrait integrated smoothly into the background area
- moving video feature inside the actual card
- working call, save-contact and motion-toggle buttons

## Publish

1. Upload the contents to a GitHub repository.
2. Keep `index.html` in the root.
3. Enable GitHub Pages.
4. Use the published URL for the NFC tag.

Open `config.js` and change the text or number as needed.
