# Glen Coxon — Horizontal Mobile NFC Card Update

This is the updated version of the **Glen Coxon** GitHub Pages card, for your existing `iroves/Glenc` repository.

## Changes

- Uses a **horizontal / side-by-side hero layout on a mobile phone**, instead of a full-width image above all the text.
- Glen's photo is **larger, brighter and softly feathered into the animated midnight-blue background**.
- Removed the entire **WHAT I DO** section and service tiles.
- Removed the **Pause Motion** button; the background video still loops silently. Users with reduced-motion preferences see the still background instead.
- Buttons in the order: **Call → Send a message → Save contact**.
- **Send a message** opens the phone's built-in **SMS messaging app** addressed to Glen, using his phone number from the provided business card.
- Call, Save Contact (VCF), Share Card, and moving video remain.

## Upload to GitHub Pages

1. Download and unzip this package.
2. Open your GitHub repository: https://github.com/iroves/Glenc
3. Upload the **files inside this folder** into the repository root. Replace `index.html`, `style.css`, `config.js`, `app.js`, and the `assets/` items.
4. Commit changes and wait for Pages to deploy. Keep the same URL: https://iroves.github.io/Glenc/index.html
5. If the old card is cached, do a hard refresh or test in a private browser tab.
