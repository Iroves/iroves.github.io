# Glen Coxon — Vertical Mobile NFC Profile

A **vertical, portrait-first digital card** designed for smartphone screens, with:

- Custom GC monogram logo in `assets/GC-logo.png`
- Glen's existing painter portrait integrated into a moving blue video backdrop
- Midnight navy and champagne-gold styling inspired by his original business card
- No "DIGITAL CARD" badge
- Call, Send a message (SMS), Save contact (`.vcf`), and Share
- Free GitHub Pages hosting; no paid card platform or domain

### Publish
1. Extract this ZIP.
2. Go to your GitHub `Glenc` repository.
3. Upload **all the files and the `assets` folder from inside** `Glen_Coxon_Vertical_NFC`, replacing the old `index.html`, `style.css`, `app.js` and `config.js`.
4. Commit the update. Give GitHub Pages a minute to redeploy.
5. Visit `https://iroves.github.io/Glenc/index.html` on your phone and refresh. The existing NFC URL remains unchanged.

### Edit details
Edit only `config.js`. To replace Glen's portrait, place a new file in `assets/` and update the photo path in `config.js`.

### Note about the reference
The requested John card URL was inaccessible from this environment, so this is a portrait-oriented, single-column interpretation of the requested style, **not an exact duplicate** of that web page.

### Preview/testing
The background video is muted, loops automatically and has a still fallback poster. Visitors using reduced-motion settings see the still background.
