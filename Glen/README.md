# Glen Coxon — Clean NFC Card

A cleaner NFC digital business-card landing page for **Glen Coxon**, built around painter/decorator branding patterns:

- clear typography
- obvious phone contact
- simple service categories
- premium but uncluttered presentation
- moving video feature **inside the actual card**

## Notes

This version was refined toward a cleaner painter/decorator look similar to common painter business-card and website patterns: simple contact-first structure, restrained palette, clear services, and a polished trustworthy feel.

The motion effect is built into the top NFC card itself, rather than dominating the full page.

## Publish on GitHub Pages

1. Upload all files to a new repository.
2. Make sure `index.html` is in the root.
3. Enable GitHub Pages.
4. Program the published URL into the NFC tag.

## Easy edits

Open `config.js` and change the text or phone number if needed.
