# Collective Wedding Styling | Luxury NFC Digital Card (V4)

## Open / upload
Open `index.html` in a browser to preview. To put it online, upload `index.html`, `styles.css`, `script.js`, and the complete `assets/` folder into a GitHub Pages site, or any standard static hosting.

## What's included
- Transparent official CWS logo (user supplied).
- Founder shown on the right, blended into warm flowers and candlelit details.
- Golden animated streaks that run quickly across the poster (real CSS/SVG animations).
- Five icon-only working buttons: consultation, phone, Instagram, portfolio, save contact.
- Service cards underneath: wedding florals, centrepieces, dance floor and bridal home styling.
- Optional reference render included as `concept-preview.png`, for look and feel.

## Before publishing
**The founder name “Liane” is PROVISIONAL and should be verified.** It is currently written inside `index.html`; update the text before publishing. The stylised portrait derives from a previous creative concept, rather than a documentary photo; the original supplied photo remains in `assets/founder-original.jpg`.

Contact details, social handles, links and reuse permissions should be double-checked with the business owner.

This is the website displayed when someone taps the NFC tag. Encoding the final hosted website URL onto the NFC chip is a separate step.
