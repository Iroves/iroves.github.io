OFFGRID / DIGITAL IDENTITY TEMPLATE

An original reusable personal-profile and portfolio concept inspired by the clarity, scale and spacing of product-led editorial websites. It uses no Apple branding or assets.

PREVIEW
Extract the ZIP and open index.html in a browser. Desktop and mobile layouts are included. No installation, paid service or external dependency is required.

PERSONALISE
1. In index.html replace Alex Morgan, the biography, role and example project descriptions.
2. Replace hello@example.com in index.html AND script.js with your email.
3. Change the AM initials in the metallic card sculpture to your own initials.
4. Replace example project href values with your project URLs if you want separate project pages. They currently link to the contact section.
5. Set --accent in style.css for the default colour. The colour buttons in the footer allow a live orange, lime or lilac preview.
6. Change the page title and meta description in index.html.
7. Remove the illustrative-content notice only after replacing all demo content.

DESIGN
Cream/charcoal palette. Oversized editorial typography. An original metallic monogram sculpture built with CSS. Asymmetric project layouts. Mobile navigation, reduced-motion support and keyboard focus styles. Copy-email control with a manual fallback when clipboard access is unavailable.

PUBLISH
Upload index.html, style.css and script.js together to your preferred static hosting provider. Keep the filenames unchanged.

VALIDATION
Local asset references and JavaScript syntax were checked. This version has not been browser-rendered in this turn.
